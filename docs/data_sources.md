# Historical Source Evidence

The fixture uses three official source families selected from pre-existing
historical excerpts. Only old public factual fields are retained.

## World Bank historical indicators

- Publisher: World Bank.
- Official reference: [World Bank Open Data](https://data.worldbank.org/).
- Selection: 24 country/indicator observations for 2020 and 2021.
- Included: country, indicator code and name, period, value, unit, observation
  and a portfolio-only evidence digest.
- Excluded: raw responses, current indicator periods, and unused metadata.

## USAspending completed awards

- Publisher: U.S. Treasury / USAspending.
- Official reference: [USAspending](https://www.usaspending.gov/).
- Selection: 4 institutional awards with end dates no later than 2021.
- Included: award ID, agency, institutional recipient, description, dates,
  award amount, and a portfolio-only evidence digest.
- Excluded: personal contacts, raw responses, active/current opportunities,
  and awards ending after the cutoff.

## NVD historical vulnerability metadata

- Publisher: NIST National Vulnerability Database.
- Official reference: [NVD](https://nvd.nist.gov/).
- Selection: 42 CVE records published no later than 2021.
- Included: CVE ID, publication and modification dates, CVSS facts, weakness
  IDs and a portfolio-only evidence digest.
- Excluded: current vulnerability records, full descriptions, configurations,
  references, affected-product inventories, and raw responses.

## Rights boundary

The selected rows contain public institutional facts only. The portfolio
preserves attribution and fixture lineage while excluding raw source bodies and
private archive metadata. Current terms, attribution rules, rate limits, and
downstream delivery rights must still be reviewed before any new commercial
release.
