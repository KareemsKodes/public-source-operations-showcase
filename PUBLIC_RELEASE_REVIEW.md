# Public Release Review

This checklist records the boundary for the public GitHub portfolio release.
The repository is intended to show finished work and observable product
behavior without exposing personal information, live customer material, or
the private implementation.

## Included

- Historical public facts with a cutoff of 2021-12-31.
- Sanitized evidence snapshots, source attribution, and portfolio digests.
- Generated HTML, CSV, and JSON exhibits.
- High-level descriptions of the data workflow and service experience.
- Elkwai brand-safe case-study artwork.

## Excluded

- Personal name, address, phone number, or personal email.
- Credentials, tokens, passwords, private keys, private hostnames, IP
  addresses, local filesystem paths, and service configuration.
- Customer, payment, usage, sales, or operational records.
- Current feeds, live product data, and private source inventory.
- Collectors, orchestration, deployment topology, tests, build metadata,
  implementation source, and release-scanner logic.
- Proprietary ranking, scoring, correlation, entity-resolution, and
  product-generation methods.

## Release decision

The public bundle is suitable for portfolio display after review of the
working tree and after replacing the private repository history with a fresh
sanitized public history. The repository license continues to reserve the
implementation and does not grant permission to copy, redistribute,
commercialize, or deploy the private systems.
